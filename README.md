# 🍔 IronGrill Smash — Burger App

Aplicativo Android nativo desenvolvido em **Kotlin** com **Jetpack Compose**, focado na experiência de pedidos para hamburgueria artesanal.

### 📱 Principais Telas:
* **MenuScreen:** Catálogo principal e navegação por categorias.
* **CustomizationScreen:** Seleção de ponto da carne, adicionais e observações com cálculo dinâmico de valor.
* **CartScreen:** Resumo do pedido, itens adicionados e cálculo final com taxa de entrega.

### 🛠️ Tecnologias:
* Kotlin
* Jetpack Compose (Material Design 3)
* Git / GitHub Flow
